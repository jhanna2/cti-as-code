SLOW MANIFEST: settlement diversion through booking platforms

Published 2026-08-27 · vendor threat report · source class: open

We track a cluster designated SLOW MANIFEST targeting freight-booking platforms at several operators. The objective in every observed intrusion has been settlement and payout data rather than credentials, ransom, or persistence for its own sake.

Observed tradecraft

  • Initial access via an integration token recovered from a vendor-side support portal. No exploitation of the platform itself was observed.
  • Enumeration of object storage using the integration's own credentials, preferring ListObjectsV2 with a prefix filter over full bucket listing.
  • Staged egress of settlement exports to an S3-compatible endpoint under actor control, throttled to resemble a reporting job.
  • Cleanup limited to control-plane audit suppression where the token permitted it.

Mapped techniques: T1530 data from cloud storage, T1078.004 valid cloud accounts, T1567.002 exfiltration to cloud storage.

We assess with moderate confidence that the actor is contracted rather than strategic, based on target selection tracking quarter-end settlement cycles.
