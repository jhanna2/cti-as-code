ManifestKit 3.2.1 security release

Published 2026-08-19 · ManifestKit maintainers · source class: open

ManifestKit 3.2.1 fixes EX-2026-0001, a deserialisation flaw in the booking-manifest importer. A crafted manifest file processed by manifestkit.io.load_manifest() can achieve remote code execution in the importing process.

All versions before 3.2.1 are affected. There is no configuration-level mitigation; the importer path is reached by any call that reads a manifest from an untrusted path. CVSS 8.8.

Operators who accept manifests from third parties should treat this as priority. Upgrade to 3.2.1 or later.
